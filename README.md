# TUKUO! — Website toko barang second

Website katalog sederhana untuk tugas HTML, CSS, dan JavaScript. Desain memakai warna hitam-putih dan layout responsif.

## Menjalankan

1. Ekstrak folder proyek.
2. Buka `index.html` di browser.
3. Pastikan internet tersedia agar foto produk dari Unsplash dapat dimuat.

## Isi proyek

- `index.html` — struktur halaman dan elemen toko.
- `style.css` — warna, tipografi, layout, dan tampilan responsif.
- `script.js` — data contoh produk, filter, pencarian, dan keranjang.

Data produk disimpan di dalam `script.js`. Keranjang hanya tersimpan selama halaman terbuka; belum ada database, akun pengguna, stok, atau pembayaran sungguhan.
